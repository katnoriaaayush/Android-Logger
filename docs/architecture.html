logdaemon — Flow State Architecture

init.rc Native Daemon  ·  Android Log Capture System

1Boot
  • init reads logdaemon.rc at boot
  • Daemon started as  uid = 0  (root)
  • Waits for  sys.boot_completed = 1  before proceeding
  • Auto-restarts every 5 s if process exits
boot_completed = 1
2USB Detection
  • Scans  /mnt/media_rw/  every 5 s
  • Finds log.sinfo → reads package list + min log level
  • File closed immediately after read — no USB handle retained
  • Loops back if log.sinfo not found
↺  log.sinfo not found — sleep 5 s
log.sinfo found
3Session Start
  • Creates  /data/media/0/LogDaemon/logs/<timestamp>/
  • Opens  .log  and  .tsv  writers per target package
  • Spawns sync thread
  • Forks  logcat -T <last_ts>  as root — replays ring buffer from last checkpoint
threads running
4Active Session
── running in parallel ──
Main Thread
  • Reads logcat pipe as root
  • Captures logs from all user profiles
  • Matches PID → target package
  • Writes .log / .tsv to internal storage
  • Checkpoints .last_ts every 64 lines
Sync Thread
  • Wakes every 5 s
  • Checks USB via  stat()
  • Reads offset → streams 64 KB chunk
  • open → fwrite → close  per cycle
  • 3 consecutive misses = USB gone
USB ejected  (3 consecutive misses · 15 s)
5Session End
  • g_usb_gone = 1 → capture loop exits cleanly
  • Log writers flushed and closed
  • _summary.tsv written to internal storage
  • Sync thread performs final USB flush
  • Process exits → init restarts daemon after 5 s
↺ init restarts logdaemon after 5 s  →  returns to USB Detection (step 2)
